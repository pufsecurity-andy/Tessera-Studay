Tessera ASIC：架構與需求

CRD 把 Tessera 定義為「在 OCP 公開開發的下一代 Azure Integrated HSM」：一顆 PCIe Gen6 端點的 HSM ASIC，以 Caliptra 2.2 為唯一的信任根，目標是 FIPS 140-3 Level 3 全晶片邊界。這一頁把規格裡的 375 項需求整理成晶片方塊、效能目標與實作現況，並附上可搜尋的完整需求清單（原文照錄）。

03效能目標

CRD 的 PERF 表，加上 key mover 與 host memory hasher 的速率需求。規格特別要求：混合（hybrid）PQC 運算時，PQC 與傳統（RSA/ECC）加速器必須同時跑滿各自的額定速率，而且 AES 與雜湊引擎在多數公鑰運算中也會被用到。
